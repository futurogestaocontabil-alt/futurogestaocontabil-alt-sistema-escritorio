# Documentação local

1. requisitos/escopo-plataforma-futuro.md contém a cópia de trabalho do documento fornecido, com a credencial exposta removida.
2. estrutura.md descreve a organização de pastas.
3. pendencias.md registra os materiais que ainda dependem de obtenção ou definição.
4. arquitetura fica reservada às decisões de arquitetura que forem efetivamente tomadas.
5. private contém o original e o registro de integridade; não publicar.
6. regras-de-negocio-e-processos.md consolida o fluxo completo, as regras implementadas, os limites atuais e os riscos que precisam de correção.

A existência destas pastas não indica que os módulos já estejam implementados.
